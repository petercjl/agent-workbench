# 适配与验证范围

Mac 与 Windows 的安装器均使用 Node.js，直接解析各自 codex-own 的独立数据目录。第一版验证了首次安装、重复安装、更新、备份、回滚、当地字符文件和原有账号/API 配置保护；通过两端实际 CLI 的 prompt-input 检查了规则和 Skill 发现。新会话内的模型行为和所有业务工具仍需按任务分别验收。

四组方法中，Skill 验证脚本需要 Python；Windows 干净环境可能需要另行安装 Python。宿主提供的基础 skill-creator 会在 discovery 中解析，doctor 只反映当前文件依赖；原生生图、浏览器、隔离 Agent 和面板能力按实际宿主判断。

可视化规划随包附带固定 Node.js 渲染器和 MIT 许可。可移植性扫描对其供应商代码中说明浏览器存储行为的 file URI 注释产生一次提示；人工检查确认该注释不包含机器路径，也不执行导航，固定供应商文件及校验哈希保持完整。

23 个 npm 组件登记来自原版的 npm 所有权链接。登记只提供选择与来源，未逐项承诺兼容；实际安装需要组件暴露 canonical skill source 合同。服务授权、原生依赖、公司数据和具体业务输出由各组件检查。

干净上下文回归未自动运行；只有用户明确要求且存在确认过的标准产物时执行。
