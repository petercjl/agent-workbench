# Planning And Confirmation

Substantial Skill work begins with a planning artifact, not disk mutation. The plan states the recurring problem, I→S→O, target/profile, knowledge mode and gaps, control topology, execution resources, capabilities/adapters, files, validation, and `READY` or `BLOCKED` status.

Wait for user confirmation before creating, replacing, installing, routing, or migrating the Skill. Once confirmed, the implementation may proceed through the authorized scope without repeatedly asking about routine reversible steps.

Read-only review does not authorize editing. Test authorization does not authorize patching. Regression evidence does not authorize an automatic next iteration.
