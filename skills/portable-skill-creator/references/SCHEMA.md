# Knowledge Layer Schema

This directory is the routed mini Wiki for portable Skill design.

Runtime navigation:

1. read this file, `index.md`, and the recent entries in `log.md`;
2. choose one realistic route under `queries/`;
3. read only the topic pages linked by that route;
4. return to the main line in `SKILL.md`.

`topics/` contains synthesized method and boundary knowledge. `queries/` maps real requests to the minimum topic set. `source-manifest.md` is maintenance provenance and is not a default runtime read.

Source classes are `W` (traceable knowledge source), `U` (user-confirmed), `E` (verified execution/platform evidence), and `A` (Agent-derived method or hypothesis). Material `A` claims stay provisional until verified or confirmed.
