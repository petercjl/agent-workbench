# 验收阅读体验

首屏给一句结论、关系图和行为条目。决策只在对应条目内出现；深层实现细节折叠。图画关系与变化，文字保留理由、取舍和证据。中文标签保持短且明确，图过宽放局部滚动容器。

输出目录包含 plan.json、plan.src.html、plan.html、manifest.json；修订另有 delta.json。每次使用新目录保存版本，避免覆盖。HTML 为派生视图，状态只以 JSON 与单独反馈/批准收据为准。

检查内容完整性、图与条目对应、全部决策与验收可见。浏览器检查 390px/1280px，图表允许内部横向滚动，页面本身不溢出；深浅主题、键盘展开和生成反馈正常。可用浏览器时检查实际页面，无浏览器则报告未视觉验收。

用同一事实材料的文字与图解比较：是否能复述目标、范围与风险，是否更快定位决策和本次修改，是否减少追问。记录实际体验，不宣称生成图就证明理解变快。
