# Knowledge routing

This is the Skill's compact, shareable knowledge layer. Load it only at main-line step 3, then read `index.md`, recent `log.md`, one matching `queries/` route, and that route's required pages. Return to the main line after the audit. `source-manifest.md` is maintenance provenance, not an ordinary runtime read.

Source classes: U = user-confirmed method, W = permitted knowledge source, E = observed execution, A = proposed inference. Never promote A to a verified platform fact.
